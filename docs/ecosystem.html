How it fits together

HubidubiTask Ecosystem

One app for tasks, notes and feeds, on Android, macOS and Linux. A phone and a computer pair once and keep each other current over your own Wi-Fi. Each has a full copy and works on its own. Four kinds of AI review items, and Claude turns changed web pages into tasks.

Devices and connections

Solid lines carry your items: to the other device, and as text to your own agent with a review. Dashed lines are questions to an AI or a feed's look at a page. There is no server of ours anywhere.

AI

Settings offers four AI choices on every system: SelfHostedAI, the default, then OpenAI, Claude and Agent, which is the AI agent the user already runs at home. There is no chat: the AI reviews any item you long-press. Feeds always write their task with Claude: a page's text comes from strangers, and the user's own agent can run commands.

A review by your own agentWhat goesWhat comes back
OpenClaw, Hermes, any OpenAI-shaped serverOne message: how to answer, the projects, open tasks, notes and calendar as text (at most 24,000 characters), the questionThe answer, and changes in a fenced JSON block
opencode, KiloA new session with the same, and a JSON schemaThe answer and the changes as schema-held JSON; the session is deleted

The agent answers with its own model and tools, as the user set it up. The app checks every change it asks for against the items (a known project, an open task, a real date) and makes it itself, once.
