# Deploy

Getting HubidubiTask to people and machines, one folder per destination.
Inside each, numbered folders are the steps in order.

| Folder | What it is for |
|---|---|
| [`google-play/`](google-play) | Publishing the Android app on Google Play: the bundle, listing, graphics, privacy policy, app content answers, release |
| [`website/`](website) | Publishing the website, with the free Mac and Linux downloads and the Agent |
| [`harness/`](harness) | Installing the Agent (the Harness) on a computer at home |
| [`omarchy/`](omarchy) | An Omarchy installer image with the app installed |
