# gtd-weekly-review

Generate the weekly review checklist.

Use when the user asks to run their weekly review, or to check the health of
their system. Read-only. Surfaces, prominently, the defining GTD failure — a
project with no next action — along with an empty-inbox check, overdue
waiting-fors, someday items untouched for 90+ days, and a calendar look-back
and look-ahead.
