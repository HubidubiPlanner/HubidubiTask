# gtd-clarify

Propose a GTD classification for one inbox item.

Use to help process the inbox: given one captured item, propose whether it is
actionable, whether it is a single next action or a project, its context, a
rough time and energy estimate, and whether to delegate or defer.

**Proposes; never commits.** The user confirms, edits, or rejects the
proposal, and only then is it filed (by gtd-file). A wrong auto-filed item is
worse than an unprocessed one, because the user stops trusting the inbox.
