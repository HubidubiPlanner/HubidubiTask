Plug in your own agent

Already run an AI agent at home? Point the app at it: Settings, AI Agent, Agent, its IP and its token. Every review can then look across all your items, use the agent's own tools, and add or finish tasks when you ask.

What it can do

  • See all your projects, tasks, notes and calendar, not just the item you asked about. They go with the question, as text.
  • Use its own tools: the web, its MCP servers, whatever you gave it.
  • Add a task, capture a thought or mark a task done, when you ask it to. The change lands in your app and syncs as usual.
  • Answer with whatever model it runs, for example Qwen on your own machine.

What it never gets

  • Your feeds. A feed's text comes from a stranger's web page, so feeds write their task with Claude.
  • An unencrypted connection outside your home network. Without HTTPS, the app talks only to addresses at home.
  • A copy of your items to keep, where the app can see to it: with opencode and Kilo, each question's session is deleted once it has answered.

The agents it finds

Each listens on the network by itself once you turn it on, with a token or password of your choosing. The app works out which one answers.

  • OpenClaw

    In its gateway settings: bind to the LAN, turn on the chat completions endpoint, and set a gateway token. Port 18789.

  • Hermes Agent

    API_SERVER_ENABLED=true API_SERVER_HOST=0.0.0.0 \ API_SERVER_KEY=a-long-secret hermes gateway

    Port 8642.

  • opencode

    OPENCODE_SERVER_PASSWORD=a-long-secret \ opencode serve --hostname 0.0.0.0

    Port 4096.

  • Kilo

    KILO_SERVER_PASSWORD=a-long-secret \ kilo serve --hostname 0.0.0.0 --port 4097

    Kilo picks a random port unless you give one; type it in the app.

  • Ollama

    OLLAMA_HOST=0.0.0.0 ollama serve

    Port 11434. It takes no token: anyone on your network can use it. Reviews use the first model it lists.

Any other server that speaks the OpenAI chat API works too, with the first model it lists.

Plug it in

The token opens that computer: anyone who has it can make the agent run commands there. Keep it long and keep it at home. Where the agent offers HTTPS, as OpenClaw does, turn it on; the app pins its certificate.

  1. Turn on its network mode

    As above, with a token or password of your own.

  2. Open the port

    Only if a firewall is on, as it is on Omarchy. For opencode:

    sudo ufw allow from 192.168.0.0/16 to any port 4096 proto tcp

  3. Choose it in the app

    Settings, AI Agent, Agent. Type the computer's IP and the token; it is kept as you type. The port can stay empty for OpenClaw, Hermes, opencode and Ollama. It says Connected and names the agent it found.

  4. Review something

    Long-press any item and choose Review with AI.
