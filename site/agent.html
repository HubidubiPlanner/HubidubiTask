Run your own Agent

The Agent is Claude Code on a computer in your home. Choose it in Settings, type its IP and port, and every review can look across all your items and the web, and add or finish tasks when you ask.

Coming soon For Linux and macOS

What it can do

  • Read and search a copy of all your projects, tasks, notes and calendar, not just the item you asked about.
  • Fetch web pages, and hand parts of a question to helpers of its own.
  • Add a task, capture a thought or mark a task done, when you ask it to. The change lands in your app and syncs as usual.
  • Answer with your Claude plan, or with a model you run yourself.

What it never does

  • Run commands or change files on the computer it lives on.
  • Answer anyone outside your home network.
  • Keep your items. Each question gets a fresh copy, deleted when it has answered.
  • Use any tools for feeds. A feed's text comes from a stranger's web page.

What you need

A Linux or macOS computer at home that stays on, for example the one that serves your own models.

  • Claude Code

    Signed in once, or pointed at a model you run. Install it from Anthropic, then run claude once.

  • Python 3.9 or later

    The Agent is one Python file with nothing else to install. macOS and most Linux systems have it already.

  • openssl

    Used once, on first start, to make the Agent's own certificate. Your devices pin it when you save.

Set it up

On the computer that will run it. It starts with the computer from then on.

  1. Unpack and install

    tar -xzf hubidubitask-agent.tar.gz sh hubidubitask-agent/install.sh

    At the end it prints the IP and port to type in the app. The port is 8765.

  2. Open the port

    Only if a firewall is on, as it is on Omarchy:

    sudo ufw allow from 192.168.0.0/16 to any port 8765 proto tcp

  3. Choose it in the app

    Settings, AI, Agent. Type the IP and the port, then Save. It says Connected when the Agent answers.

  4. Review something

    Long-press any item and choose Review with AI.

Use a model you run

Point Claude Code at a server on your network that speaks Anthropic's Messages API. Edit this file on the Agent's computer, then restart it.

~/.config/hubidubitask-harness/harness.env ANTHROPIC_BASE_URL=http://127.0.0.1:8080 ANTHROPIC_AUTH_TOKEN=local ANTHROPIC_MODEL=glm-5.2 CLAUDE_CODE_SUBAGENT_MODEL=glm-5.2

Restart: systemctl --user restart hubidubitask-harness on Linux. On a Mac, run the installer again.
